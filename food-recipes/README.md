# React Vite Project

This project focuses on performance, clean UI, reusable components, 
and real-world frontend features like filtering, caching, routing, 
and state management.

## 🛠 Tech Stack

- ⚛️ React
- 🟦 TypeScript
- ⚡ Vite
- 🎨 Material UI (MUI)
- 🧠 Redux Toolkit
- 🌐 React Router DOM
- 🔗 Axios (API Handling)
- 🎞 Framer Motion
- 🧪 Playwright (Testing)


## ✅ Topics Covered
- React Hooks & State Management
- Redux Toolkit 
- Query Params based Filtering
- Debouncing Search
- Checkbox & Slider Filters
- UI Animations
- Playwright E2E Testing
- Material UI Components
- Responsive Layout
- Skeleton Loaders
- Animations using Framer Motion
- Tooltip, Chips, Sliders, Tables
- Lighthouse Performance Report
- Error Boundaries
- Tag Based Filters
- List / Grid View Toggle
- IFrame Integration
- Internationalization 
- Captcha/reCaptcha
- hCaptcha
- Chat Setup with Socket.io


## 🚀 Getting Started
npm install  
npm run dev
